## П.4 Місце (реєстрація з settings.local.json; нічого не змінено)
Хука на Read/Grep/Glob у проєкті немає (глобальний ~/.claude/settings.json має Read-хук на файли >300 рядків). Лічильника викликів у ході/сесії немає ні в кого, крім edit-gate.
1. edit-gate-hook.py (PreToolUse Edit|Write|MultiEdit|Bash): уже читає весь журнал сесії (iter_tool_uses → Evidence), має журнал ключів на сесію (ключ «agents@{лічильник//N}» дасть повтор кожні N читань), non-blocking additionalContext і режим --backtest <jsonl>. Додати: скидання лічильника на Agent, +1 на читання. Мінус: тема «перед правкою».
2. cost-nudge-hook.py (UserPromptSubmit): готовий шаблон «поріг, раз на поріг, state за sid, fail-open»; на чверть менше спрацювань ніж п.1 при N=20 (129 проти 173), ті самі 4/8 і 2/3. Мінус: лише на межі повідомлень, не всередині довгого ходу.
Перед будь-яким варіантом: у підсесії журнал уже містить 'PreToolUse:Bash' hook_additional_context, а в хуках немає перевірки agent_id/subagents — потрібна заглушка для підагентів і для ANTHROPIC_BASE_URL *deepseek* (як classify-task.sh).
