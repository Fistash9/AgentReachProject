# Реєстр класів помилок — v1 (2026-10-16)

Служить: Q12 «Реєстр класів помилок з підрахунком повторів». Запит користувача «зроби як буде краще для
реєстру помилок» → бриф → «Спершу 1 і 2, потім покажи». Звідки зміни (сліпа звірка, backtest-results.md):
v0 збігався з незалежною розкладкою лише 24/48; «записане не спрацювало» виявилось властивістю будь-якого
класу, а класи 2/4/5/13 v0 — однією родиною з різними ознаками.

## Дві осі
- **Клас** — механізм помилки (нижче, Р1–Р9).
- **Позначки** (окремо від класу):
  - `повтор` — користувач прямо каже, що це вже було («знов», «я казав», «вже казали», «ми ж записували»);
  - `після ліків` — для класу вже був записаний захист (пам'ять, правило, хук) — це колишній клас 1 v0.
