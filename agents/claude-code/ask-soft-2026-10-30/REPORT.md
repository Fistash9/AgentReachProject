## Варіанти для користувача
1. softplus (рекомендація під-агента): жодного відбиття; користувач бачить «⚠ Не звірено» у віконці замість тексту без
   жодної перевірки.
2. soft+HARD_MECH: позначка, але плани механізмів без звірки — deny (RULES-WHY 2026-10-22: «Звірка не потрібна»
   пропустила 4 плани механізмів); цієї сесії не прибрав би 2 відбиття з 3.
3. soft: позначка лише для агента — найменше тертя, найменше видно користувачу.

Перед увімкненням — живий тест одного віконця: чи справді воно з'являється з позначкою.
