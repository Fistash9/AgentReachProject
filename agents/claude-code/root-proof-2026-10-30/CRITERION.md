# Перевірка гіпотези «діє те, що не обійти» — критерій НАПЕРЕД (записано до даних)

Запит користувача 30.10: «гіпотеза не підходить, спочатку докази» → «Перевірку — зараз».
Попередня гіпотеза «слова замість стану» — спростована (labels.csv × outcomes.csv).

Одиниця: гілка механізму (хук/сигнал) зі своїм логом спрацювань.
Мітка (сліпо, під-агент 1, без логів): НЕ_ОБІЙТИ — блокує/не відпускає, доки дію не змінено, фрази-обходу нема;
ФРАЗА — блок/голос знімається фразою чи міткою агента; ПІДКАЗКА — лише додає текст; ASK — дозвільне віконце.
Результат (сліпо, під-агент 2, без гіпотези): частка повторів у межах сесії = (спрацювань − сесій зі спрацюванням) / спрацювань,
з логу самої гілки, усі доступні дати; плюс те саме за 27–29.10.

ПІДТВЕРДЖЕНО: медіана частки повторів у НЕ_ОБІЙТИ щонайменше вдвічі нижча, ніж у ФРАЗА і в ПІДКАЗКА, і в кожній групі ≥3 гілки з даними.
СПРОСТОВАНО: різниці менше ніж удвічі або зворотна при ≥3 гілках у групах.
НЕ ВИРІШЕНО: <3 гілок з даними хоч в одній групі.
Відома слабкість: частота спрацювань залежить від кількості нагод; повтор блоку може означати повторну спробу.
