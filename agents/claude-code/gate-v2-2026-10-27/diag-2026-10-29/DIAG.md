## 2. Корені
- К1. Причину хук шукає лише в `description` (:500, :502). У Edit/Write/MultiEdit цього поля немає. Для Bash виняток «edit» закрито (:467). Випадок (б).
- К2. Гілка C повертає deny раніше, ніж до черги доходить `wl` (:514–519), тому виняток «check» мертвий за C=1 (:520). До того ж `RE_WL_CHECK` (:392) не бачить «цитат/верифікатор/verify-before-show».
- К3. `RE_GIT_OWN` перевіряється через `.match`, тобто з початку команди (:397, :494). Префікс-причина ламає виняток для git.
- К4. Старт сесії і робота в tmp-пісочниці рахуються в N (:511, :522; якір «start» :444).
- К5 (вимір). Дедуп (:559) пропускає будь-який повтор, тож винятки лише здаються робочими.

## 3. Правки (К1–К3 — у копії `fix/`, `fix.diff`)
- К1: `+ desc = v2_reason_text(inp)` (description + префікс `: "…без агента:…"`). Edit/Write ≤10 рядків звільняються автоматично. Bash «правк/запис» ≤10 рядків → "edit".
- К2: `+ if wl == "check": return None` перед C. `units` без кроків, що мають виняток (`v2_wl_of(...) is None`). `RE_WL_CHECK += |цитат|верифікатор|verify-before-show`.
- К3: `RE_GIT_OWN = r"\s*(?::\s*(?:"[^"]*"|'[^']*')\s*&&\s*)?(?:cd \S+ && )?git …"`.
- К1в: Bash-запис ≤10 рядків у *.md — автоматично [не перевірено].
- К4: не рахувати Read `.baton/HANDOFF.md`, `tools/baton-diff.py`, чергу (0), дії лише в `$PREFIX/tmp` [не перевірено].
- Перевірка без побічних ефектів: `python3 -I sim.py <хук>` (9 синтетичних входів, LOG у tmp, UUID-сесія). Orig: 7 з 9 — DENY на першому виклику, повтор проходить через дедуп. Fix: 2 DENY (крок 6 без причини — так задумано; 9 — контроль). `python3 -I replay.py` — живі orig/fix.
