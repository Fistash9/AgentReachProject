- **B** — «без агента:» знімає ворота лише з причиною з білого списку:

- **C** — після звіту під-агента (task-notification `Agent "…"` або `MCP task (delegate)`, hand-back) дозволено K=2 кроки. Далі deny з текстом «доробка — віддай наступному агенту». Вікно закриває нова роздача або нове повідомлення користувача.
- **Z** — законна робота оркестратора не рахується:
  - усе після «закрий сесію» або виклику Skill session-close у ході;
  - git status/add/commit/log/diff/show;

- **G** (вимкнено) — delegate, deepseek і SendMessage теж скидають лічильник.
