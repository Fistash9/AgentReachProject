## Висновок (3 рядки)
- Є докази: блокування в момент дії (deny-хук / permissions) працює щоразу, але лише для правил, які можна перевірити механічно (Anthropic, #70420 — якісно); повторення вимог ближче до моменту дії частково повертає якість (Laban: +15–20% втраченого, recap 59→77 із 93); що більше правил і що довша сесія, то гірше (IFScale, 2402.10962).
- Лише поради без вимірів: короткий CLAUDE.md (<200 рядків), /clear після 2 виправлень, нагадування на кожен промпт (lexler; Spence — «надійніше», його числа старі й не відтворені), Memory Bank, правила Cursor/Copilot.
- Правило «бути уважнішим», яке хуком не перевірити, не розв'язав ніхто: issues закриті ботом, у мейнтейнерів відповіді немає; людський аналог (Онтаріо) — чекліст без справжнього використання не дає ефекту.
