## Який тип реально зменшив повтори
1. Блоки/замки на дії з видимою шкодою (коміт, шифри в питаннях, mv знімків, процеси) — повторів після ліків 0 (Р2, Р6).
2. Підказки хуків і голоси — частково: голос черги тримає, підказки edit-gate/troubles-grep здебільшого ігнорують (5 з 8, 105 з 116); рецензія 20.10: «слухались лише ворота deny… підказки… — ні» (TROUBLES:5572).
3. Текст пам'яті/RULES/TROUBLES — не зменшив жодного з чотирьох випадків запиту; корінь («5 чому» №2): реакція на нагадування = ще один запис, крок «урок → ворота» без події-запуску й чекає згоди (BACKLOG:929 — 29 днів).

## Запропоноване, але не збудоване (five-whys-2 «Зміни»)
Хук «нагадування = повтор» (бектест 7/7 у сесії, 0 хибних; на 261 журналі — ~половина хибних без обмеження); поле «ворота:» у записах пам'яті (4 файли без воріт); вік рішень у черзі >7 днів.

## Не перевірено
- «Хто говорить»: число повторів і чи є механізм поза хуками — не міряно.
- Р6/Р2 «після 0» — при зламаному детекторі (37% без класу) недійсне як доказ.
- Відповідність «клас ↔ ліки» в registry-v1 — судження автора («не звірено»).
- Корисність підказок troubles-grep «2 з 30» — оцінка, не замір.
- Бектест хука «нагадування=повтор» після обмеження «коротка репліка» — не запускався.
