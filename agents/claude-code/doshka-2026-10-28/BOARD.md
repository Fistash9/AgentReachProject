## Правило вибору виконавця (з наявних правил, нового нема)

- збирання фактів за списком → під-агент Sonnet, low/medium (RULES «Під-агенти: effort і модель»);
- діагноз причини, код у копії → під-агент high;
- довге читання цілого файлу → DeepSeek з розмовою (платно, «так» з ціною);
- незалежна звірка → delegate; збій → Haiku з порожньої теки (verify-before-show, ланцюжок);
- самостійна паралельна задача з межами → DSH (лише з «(Full access)» на екрані);
- рішення (механізми, гроші, коміт, втрати) → користувач;
- план, синтез, приймання роботи (вибірково ≤2 кроки) → claude-code.
