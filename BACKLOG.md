  протокол за рік (2026-09-19)
- **Не перевірено (реальні невідомі, щоб не здивуватись пізніше):**
  чи є готовий A2A Agent Executor wrapper для CLI-агента типу
  `claude -p`, чи доведеться писати самим; A2A вимагає постійного
  HTTP-сервера (JSON-RPC 2.0 + SSE) — інша архітектура, ніж поточний
  простий polling-цикл бота
- **Важливе обмеження, не плутати:** A2A покращує СТРУКТУРУ
  делегування (Agent Card, task lifecycle), але НЕ вирішує ризик
  №2 з ECOSYSTEM.md (немає перевірки, чи інструкція DeepSeek
  коректна) — це різні задачі
- **Питання пропорційності:** чи виправданий повний HTTP A2A-сервер
  для Telegram-бота одного користувача, чи це той самий
  over-engineering, від якого відмовились сьогодні для інших ідей
- Статус: обговорити деталі перед рішенням про реалізацію
