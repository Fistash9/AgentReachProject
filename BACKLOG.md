### A2A-апгрейд telegram_deepseek_bot.py (2026-09-19)
- **Мета:** замінити крихкий regex-парсинг рядка `CLAUDE_CODE: <промпт>`
  на реальний протокол делегування задач між DeepSeek-оркестратором
  і Claude Code
- **Перевірено:** офіційний SDK `pip install a2a-sdk`, hello-world
  реалізація — приблизно 1 день роботи, 150+ компаній підтримали
  протокол за рік (2026-09-19)
- **Не перевірено (реальні невідомі, щоб не здивуватись пізніше):**
  чи є готовий A2A Agent Executor wrapper для CLI-агента типу
  `claude -p`, чи доведеться писати самим; A2A вимагає постійного
  HTTP-сервера (JSON-RPC 2.0 + SSE) — інша архітектура, ніж поточний
  простий polling-цикл бота
- **Важливе обмеження, не плутати:** A2A покращує СТРУКТУРУ
  делегування (Agent Card, task lifecycle), але НЕ вирішує ризик
  №2 з ECOSYSTEM.md (немає перевірки, чи інструкція DeepSeek
  коректна) — це різні задачі
- **Питання пропорційності:** чи виправданий повний HTTP A2A-сервер
  для Telegram-бота одного користувача, чи це той самий
  over-engineering, від якого відмовились сьогодні для інших ідей
- Статус: обговорити деталі перед рішенням про реалізацію

### claude-archive-kb — архів розмов з Claude.ai app (2026-09-18)
- **Мета:** зібрати, перевірити і структуровано зберегти напрацьоване
  в застосунку Claude (комп'ютер + телефон) — нічого не видаляти
- **Крок 1 (дія користувача):** claude.ai → Settings → Privacy →
  Export data. Anthropic шле на email ZIP з `conversations.json`.
  Посилання діє 24 год. Працює тільки з web/desktop — **на iOS/Android
  експорту немає** (мобільний і десктопний клієнт — той самий акаунт,
  тож експортувати можна через комп'ютер/веб)
- **Обмеження:** persistent memory Claude в експорт НЕ входить,
  тільки самі розмови
- **Крок 2 (аналіз):** конвертувати `conversations.json` в окремі
  `.md`-файли (по розмові/темі), індексувати через SQLite FTS5 для
  швидкого повнотекстового пошуку без повторного вичитування файлів
- **Інструменти для пошуку:** ripgrep (`rg`) замість grep — стрімить
  файл, не завантажує весь у пам'ять/контекст LLM; `jq` для
  структурного пошуку по JSON. Обидва **не встановлені** в Termux
  (перевірено 2026-09-18, `command -v rg jq` — не знайдено)
- **Готові інструменти для аналізу (перевірено на GitHub, 2026-09-18):**
  conversation-analysis-tools (CrazyDubya), claude_desktop_export_browser
  (davidteren), claude-chat-viewer (osteele), Claude-Conversation-Exporter
  (socketteer, Chrome-розширення)
- **На що звертати увагу:** секрети/ключі у тексті розмов, дублікати
  тем на різних пристроях, застаріла/суперечлива інформація, розмір
  архіву (сотні-тисячі розмов — пряме читання все в LLM неможливе)
- **Статус:** дослідити — чекає на Крок 1 (export data) від користувача
