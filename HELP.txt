📌 ПРЕФІКС
   Ctrl+B   — "магічна кнопка" tmux. Натисни її,
              потім потрібну клавішу. Відпускати Ctrl
              між натисканнями НЕ треба.

🪟 ВІКНА (у нас 3: claude / agent / shell)
   Ctrl+B, 0      → перейти у вікно 0 (claude)
   Ctrl+B, 1      → перейти у вікно 1 (agent)
   Ctrl+B, 2      → перейти у вікно 2 (shell)
   Ctrl+B, n      → наступне вікно
   Ctrl+B, p      → попереднє вікно
   Ctrl+B, w      → список вікон (вибір стрілками)

🚪 ВИХІД / ВІД'ЄДНАННЯ
   Ctrl+B, d      → від'єднатися (сесія живе у фоні,
                    агенти продовжують працювати)
   Ctrl+B, Q      → те саме (велика Q)
   Ctrl+B, &      → закрити ПОТОЧНЕ вікно (з підтвердженням)
   Ctrl+B, x      → те саме

🔁 ПОВЕРНУТИСЯ ДО СЕСІЇ
   У звичайному bash:  tmux attach -t work
   Або запустити:      ~/AgentReachProject/menu.sh → пункт 5

⚙️  СЕРВІС
   Ctrl+B, r      → перечитати ~/.tmux.conf
   Ctrl+B, ?      → відкрити цю шпаргалку (popup)
   q              → закрити popup

🌐 МЕРЕЖА / ПРОЦЕСИ
   Ctrl+B, s      → список tmux-сесій
   Ctrl+B, :      → командний рядок tmux
                    (наприклад: :kill-session)
