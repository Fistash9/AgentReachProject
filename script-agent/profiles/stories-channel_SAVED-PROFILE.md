# SAVED PROFILE: канал історій-оповідань

Сформовано 2026-09-21. Це готовий блок для слота **ACTIVE PROFILE** у `script-agent/AGENT.md` (частина 1). Копіюй усе між рядками `SAVED PROFILE START` і `SAVED PROFILE END`.

Джерела: відповіді користувача (мова, автор, формат, research, тривалість, тон, правила) і аналіз трьох референсів (`analyses/stories-refs_2026-09-21.md`). Поля з позначкою `[чернетка]` користувач окремо не підтверджував. Ніша тварин і птахів була тестовою і сюди не входить.

## Що ще не визначено

- Назва каналу.
- Теми історій за межами сімейної драми (перелік у референсах вузький).
- `PACING`, `AUTHOR PERSONALITY`, `TOPIC` (теми) позначені як чернетка.
- Референсів три, і всі з автосубтитрами, тож числа довжини речень наближені.
