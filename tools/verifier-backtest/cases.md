Джерела зібрано в `sources/` 2026-09-24 (curl, npm view, ls, копії

## Промпт задачі для оркестратора — v1 (чернетка)

Зроби бектест верифікатора: 6 кейсів, кожен двічі через DeepSeek flash,
E1 ще двічі через Agent. Порахуй, скільки помилок упіймано. Запиши в
results.md.

## Що покращено в v2 (самокритика v1)

1. Немає умови зупинки й поведінки на збоях: таймаут чи зламаний DSML
   (TROUBLES: 2 з 3 на web-задачах) не можна рахувати як «ні».
2. Не зафіксовано промпт верифікатора: без цього легко підігнати
   промпт під результат. Промпт заморожено нижче, до прогону.
3. Не сказано, що верифікатор НЕ бачить очікуваного вердикту й не
   знає, котрі кейси є помилками.
4. Не сказано, як рахувати два прогони одного кейсу: зараховано,
   лише коли обидва прогони дали «НІ». Якщо прогони розійшлися,
   записуємо нестабільність.
5. Відповіді DeepSeek самі можуть містити вигадані цитати, тому кожну
   цитату звіряю кодом (grep по файлу джерела). Вигадана цитата робить
   вердикт недійсним.
6. Не названо межі: read-only, нічого поза `tools/verifier-backtest/`
   не змінювати, не комітити без «так».

## Промпт задачі — v2 (робочий)

- **Мета:** з'ясувати, чи незалежний верифікатор (DeepSeek flash для
  фактів, Agent-субагент для судження) ловить помилки класу «висновок
  не звірено з джерелом поруч», не піднімаючи хибних тривог.
- **Вхід:** 6 кейсів нижче, джерела лише з `sources/`, ≤2 джерела на
  виклик. Промпт верифікатора — дослівно розділ «Промпт верифікатора».
- **Прогін:** кожен кейс двічі через `delegate` (task=reason,
  deepseek-v4-flash), E1 ще двічі через Agent (general-purpose).
  Кожен виклик окремий, без очікуваного вердикту.
- **Перевірка виходу:** кожну цитату звіряю `grep -F` з файлом джерела.
  Вердикт без справжньої цитати позначаю «недійсний».
- **Підрахунок:**
  - E-кейс упіймано, якщо обидва DeepSeek-прогони дали «НІ» з дійсною
    цитатою.
  - K-кейс проходить, якщо жоден прогін не дав «НІ».
  - «НЕ МОЖУ ПЕРЕВІРИТИ» і збій не дорівнюють «НІ».
- **Поріг «будуємо етап 2»:** щонайменше 3 з 4 E упіймано й 0 хибних
  тривог на K1–K2.
- **Умова зупинки:** усі 16 викликів зроблено й записано в results.md,
  або 2 збої поспіль на одному кейсі (тоді записати збій і йти далі).
- **Межі:** лише читання джерел і запис у `tools/verifier-backtest/`.
  Без комітів і без змін правил чи скілів до «так» користувача.
- **Відомий ризик:** загальні типи складових у промпті верифікатора
  (причина, межі, повнота) я сформулював, знаючи ці кейси. Результат
  може бути завищеним, тому його перевірять нові кейси на етапі 2.

## Промпт верифікатора (заморожено до прогону)

```
Ти — незалежний верифікатор. Інший агент збирається показати
користувачу твердження нижче. Звір його ТІЛЬКИ з наданими файлами-
джерелами. Власні знання доказом не вважаються. Не питай уточнень і не
називай себе Claude Code.

Кроки:
1. Розбий твердження на складові: факти, числа, причинні зв'язки
   («X через Y», «X дає Z»), межі застосування (про що саме йдеться),
   слова повноти («усі», «нічого не губиться», «немає»).
2. Для кожної складової знайди в джерелах ДОСЛІВНУ цитату, яка
   підтверджує або спростовує її.
3. Винеси вердикт:
   - ТАК — кожна складова підтверджена цитатою.
   - НІ — хоча б одна складова суперечить джерелу, або джерело
     стосується іншого об'єкта чи називає іншу причину. Наведи
     цитату-суперечність.
   - НЕ МОЖУ ПЕРЕВІРИТИ — у джерелах немає потрібного. «Не знайшов»
     не означає «НІ».

Формат відповіді (лише це):
VERDICT: ТАК | НІ | НЕ МОЖУ ПЕРЕВІРИТИ
PARTS: <складова> — <підтверджено/суперечить/немає даних>
QUOTES: "<дослівна цитата>" (<файл>)
REASON: 1–3 речення

ТВЕРДЖЕННЯ: {claim}
КОНТЕКСТ: {context}
```
