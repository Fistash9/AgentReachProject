9: A self-learning system for Claude Code that captures corrections and discovers workflow patterns — turning them into permanent memory and reusable skills.
10: 
11: **Two ways to run it:**
12: 
13: | | **Plugin** (Python) | **Mod** (`reflect-mod`, new in 3.3) |
14: |---|---|---|
15: | You correct Claude | a hook queues it | a model check sees it at once, in any language |
16: | You review | later, with `/reflect` | right away, in a band above the prompt |
17: | Runs on | Claude Code, plus Codex/Cursor via AGENTS.md | Claude Code 2.1.286+ with mods |

51: ## Key Features
52: 
53: | Feature | What it does |
54: |---------|--------------|
55: | **Permanent Memory** | Corrections sync to CLAUDE.md — Claude remembers across sessions |
56: | **Skill Discovery** | Finds repeating patterns in your history → generates commands |
57: | **Multi-language** | AI understands corrections in any language |
58: | **Skill Improvement** | Corrections during `/deploy` improve the deploy skill itself |

60: ## Installation
88: 
89: Claude Code [mods](https://claude.dev/blog/getting-started-with-claude-code-mods/) run inside the session, so the
90: same idea works without a queue you have to remember to review:
91: 
92: - **Every short prompt** (500 characters or less, not "ok"/"continue", not a slash command) goes to a one-shot
93:   model check (`haiku` by default) that decides whether it holds a reusable rule. It reads intent, not keywords,
94:   so corrections in any language count ("нет, используй pnpm" works).
95: - **A band above the prompt** shows each rule it finds, with **Save**, **Global/This repo instead**, **Edit** and
96:   **Skip**. You decide in the moment; repeats merge into one row with a count (`×3`).
97: - **Save** adds a bullet inside a marked section of `~/.claude/CLAUDE.md` or `./CLAUDE.md`, and the rule applies
98:   in the current session at once. Nothing is written without a press.
